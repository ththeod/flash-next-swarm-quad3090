Generators for the blog's charts (Jekyll ignores this folder).

- `make_html_charts.py _includes` writes the HTML charts used by `index.md` (`chart-hero`, `chart-steps`, `chart-swarm`, `chart-ratios`).
- `make_svgs.py OUT` and `make_cmp_svgs.py OUT` write the static SVG versions used by the README (`docs/images/` on the `swarm` branch).
